matplotlib's figures, in pure Go.
Tested equal where they can be equal.

go-plot is the plotting library of the Go scientific stack built on go-ndarray. Its object model and defaults are matplotlib's — figure size, fonts, colour cycle, margins, tick placement and tick labels — so a figure looks the way a matplotlib user expects. It writes SVG and PNG, sets labels with a real TeX math typesetter, and needs no Python and no cgo: one static binary, js/wasm included.

main.go
func main() {
	x := make([]float64, 200)
	for i := range x {
		x[i] = float64(i) / 199 * 10
	}
	sin, damped := make([]float64, len(x)), make([]float64, len(x))
	for i, v := range x {
		sin[i] = math.Sin(v)
		damped[i] = math.Exp(-v/4) * math.Cos(2*v)
	}

	fig, axs := plot.Subplots(1, 1, plot.FigSize(6.4, 4))
	ax := axs[0][0]
	ax.Plot(x, sin, plot.Label(`$\sin t$`))
	ax.Plot(x, damped, plot.Label(`$e^{-t/4}\cos 2t$`), plot.LineStyle("--"))
	ax.FillBetween(x, damped, nil, plot.Alpha(0.2))
	ax.SetTitle(`Two signals, labelled in TeX`)
	ax.SetXLabel(`time $t$ (s)`)
	ax.SetYLabel("amplitude")
	ax.Grid(true)
	ax.Legend()
	if err := fig.SaveSVG(os.Stdout); err != nil {
		panic(err)
	}
}

Why go-plot

The plotting library notebooks reach for first.

A census of 339 scientific notebooks ranks plotting first among the things that keep them from moving to Go, and most of them write fig, ax = plt.subplots(); ax.plot(...). go-plot is that API, under the same names, with Go's argument style.

📐

matplotlib's object model

Subplots, Plot, SetXLabel, Legend, SetTitle, TightLayout, SetYLim, Axhline: every call the census ranks, named as in matplotlib. Keyword arguments become options: plot.Color("C1").

🎯

Tested equal to matplotlib

Tick locations and labels, colormaps, named colours, and the layout of figures are compared with fixtures generated by matplotlib 3.11.2 itself, exactly unless stated.

∑

Real TeX in the labels

$...$ is typeset by go-tex/math with STIX Two Math: fractions, radicals, big operators, limits and matrices, as TeX lays them out.

🧮

Data from go-ndarray

Every data argument takes []float64, other numeric slices, or a *ndarray.Array of any of its thirteen dtypes.

🖼️

SVG, PNG, and notebooks

SaveSVG writes vector paths, SavePNG anti-aliased pixels, and Display hands a notebook kernel both.

📦

Pure Go, CGO=0

No Python, no C. It builds for the six 64-bit Linux targets, 386, arm, js/wasm and wasip1/wasm.

✅

100% test coverage

Gated in CI on three operating systems, with six architectures.

⚖️

BSD-3-Clause

Every repository of the organization.
